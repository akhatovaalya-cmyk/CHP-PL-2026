# P&L агент — CHANGEPOINT (CHP)

Streamlit-приложение: загрузка выгрузки 1С ОСВ → P&L.
Доход по видам услуг/контрагентам, прямые затраты по статьям (если есть),
админ 7211 расшифрован, 7212 отдельным блоком ниже чистого дохода,
налоги с ЗП свёрнуты, курсовая разница нетто. Сверка с 1С (контроль «Разница» = 0).

## Файлы
- `app.py` — интерфейс (Main file path для Streamlit)
- `chp_engine.py` — парсер ОСВ + генератор P&L + журнал
- `recalc_native.py` — пересчёт формул
- `requirements.txt` — зависимости
